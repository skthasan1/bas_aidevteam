# project-a: test notes

Purpose: what the product is, how to start it locally (throwaway database, dummy keys), known issues, and where its scenarios and suites live.

Copy and rename this folder for each product. Add `runs.md` (one row per run), `scenarios/<area>.md`, `suites/full.md`, `suites/regression.md`. See `qa/test-strategy.md`.

Product addendum (design overrides, confidentiality rule): add `ui-addendum.md` here if the product needs one.
