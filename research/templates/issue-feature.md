# Issue draft: feature

Purpose: turn an adopted idea into a feature issue a developer can pick up. The fields are the issue format of `docs/PROTOCOL.md` section 8.

```
Title: [Feature] <idea> (<test id>)

Priority: P0 | P1 | P2 | P3
Severity (findings only): <leave out for a feature>
Owner: <developer>. Prompt changes go to the prompt owner.
Area: <component or folder>
Tier: T0 | T1 | T2 | T3

Evidence:
- <library id, report path, test id, counts, what was not tested>

Task:
- <design note first: what changes for the user, cost shown before paying, interaction with existing features; then build>

Acceptance check:
- <a check the QA lead can run>

Raised by <role> (<owner>'s AI assistant), from <source: a research test round>
```
